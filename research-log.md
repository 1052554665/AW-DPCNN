### plot_tsne_all.py — Revised

**Three modes:**

| Mode | What it generates |
|---|---|
| `--mode models` | One t-SNE per trained backbone (6 models) |
| `--mode raw` | Single t-SNE of raw input pixels |
| `--mode all` | Both of the above |

**Usage:**
```bash
PYTHONPATH=$(pwd) python scripts/plot_tsne_all.py --mode all \
    --data-dir ./datasets/cwru_de/test --max-samples 1500
```

**Output** (all in tsne_models):
| File | Content |
|---|---|
| `tsne_MSCA_VGG16.png` … `tsne_vit.png` | Model feature t-SNE |
| `tsne_cwru_de_raw_input.png` | Raw pixel t-SNE |

**Key design:**
- t-SNE params locked to match tsne.py (perplexity=30, lr=200, max_iter=1000, init="pca")
- Raw-input uses PCA→50 dims before t-SNE (same as before)
- All plots share the same IEEE visual style via `plot_tsne()`
